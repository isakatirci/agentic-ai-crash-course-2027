1 Ne Öğreneceğiz & Neden Önemli?

Bir LLM (Large Language Model) API'sine soru sorup yanıt almak yalnızca birkaç satır kod sürer. Ancak gerçek bir şirkette çalışan yazılımlar tek bir soru-cevapla bitmez. Sistemin veritabanına bağlanması, konuşma geçmişini (State) koruması, planını güncellemesi ve hata aldığında kendini toparlaması gerekir.

Günlük Hayattan Benzetme
Klasik Prompt-and-Response, masasında yalnızca ansiklopedi bulunan bir danışmana benzer: tek seferde yanıt verir, telefon açamaz ve iki dakika sonra adınızı unutur. Virtual Environment (venv)

Thread-Safety

Modül 1: LLM Engineering & Structured Outputs

1 Ne Öğreneceğiz & Neden Önemli?

Bir Agent inşa etmeden önce onun çekirdeği olan LLM'i öngörülebilir biçimde yönetmeyi öğrenmeliyiz. Yazılımda serbest metinle işlem yapmak kırılganlık yaratır. Örneğin bir destek biletini otomatik yönlendirecekseniz kodunuzun net, doğrulanmış bir JSON nesnesine ihtiyacı vardır.

Günlük Hayattan Benzetme
Müşteri restoranda siparişi ne kadar dağınık anlatırsa anlatsın, garson mutfağa standart bir sipariş fişi verir. Structured Outputs da dağınık insan dilini yazılımın güvenle işleyeceği standart veri sözleşmesine (Schema) dönüştürür.

2 Key Terminology (Kritik Kavramlar ve Tanımlar)

Tokenization
Metnin LLM tarafından işlenebilmesi için küçük parçalara (Token) bölünmesidir. Maliyet ve hız sınırları Token üzerinden ölçülür.
Context Window
Modelin tek bir istekte hafızasında tutabileceği maksimum Token kapasitesidir (girdi + çıktı toplamı).
System Prompt
Modele rolünü, kurallarını, sınırlarını ve çıktı biçimini öğreten en yüksek öncelikli yönergedir.
Temperature
Modelin yaratıcılık/rastgelelik düzeyidir. Mühendislik ve JSON görevlerinde tutarlılık için 0.0 kullanılır.
Structured Outputs
Modelin serbest metin yerine önceden tanımlanmış bir JSON şemasına birebir uyan çıktı üretmesidir.
Immutable Dataclass
Oluşturulduktan sonra değiştirilemeyen (frozen=True) veri yapısıdır; çoklu Thread erişiminde %100 güvenlidir.

Structured Outputs & Token Budget Lab — labs/mod01_structured_llm.py
Python 3.10+ • Thread-Safe
"""
Modül 1 Hands-On Lab: LLM Engineering Temelleri
- Tokenization tahminleyici (precompiled regex ile yüksek performans)
- Context Window bütçe kontrolü
- Structured Outputs (JSON Schema doğrulama)
- %100 Thread-Safe tasarım (immutable dataclass & zero global mutable state)
"""

# Tip ipuçlarını (Type Hints) daha esnek kullanmamızı sağlar.
from __future__ import annotations

import json  # Metin halindeki JSON verisini Python sözlüğüne (dict) çevirir.
import re    # Düzenli ifadeler (Regex) ile metni parçalara ayırmak için kullanılır.
from dataclasses import dataclass  # Az kodla temiz veri sınıfları (Class) oluşturur.
from typing import Any

# Regex desenini fonksiyonun dışında 1 kez derliyoruz (High Efficiency).
# Böylece her çağrıda bilgisayar aynı deseni tekrar hesaplamaz.
_WORD_PATTERN = re.compile(r"\w+|[^\w\s]", re.UNICODE)


# frozen=True -> Nesne oluşturulduktan sonra değiştirilemez (Immutable & Thread-Safe).
# slots=True  -> Python'ın gereksiz bellek (RAM) harcamasını engeller.
@dataclass(frozen=True, slots=True)
class LLMRequestConfig:
    """Değiştirilemez (Immutable) LLM yapılandırması. Thread-Safe'tir."""

    model: str = "gpt-4o-mini"
    temperature: float = 0.0  # 0.0 = En tutarlı, sürprizsiz (Deterministik) çıktı.
    max_context_tokens: int = 4096  # Modelin tek seferde alabileceği üst Token sınırı.
    system_prompt: str = (
        "Sen bir destek bileti (Support Ticket) sınıflandırma uzmanısın. "
        "Yalnızca geçerli JSON döndür."
    )


@dataclass(frozen=True, slots=True)
class TicketClassification:
    """Structured Output sözleşmesi (Schema): Modelden beklediğimiz 3 zorunlu alan."""

    category: str
    priority: str
    summary: str


def estimate_tokens(text: str) -> int:
    """Basit ve hızlı bir Token sayısı tahminleyicisi."""
    # Metni kelimelere ve noktalama işaretlerine böler (liste döner).
    parts = _WORD_PATTERN.findall(text)
    # Türkçe eklemeli bir dil olduğu için parça sayısını 1.3 ile çarpıp güvenli tahmin alırız.
    return max(1, int(len(parts) * 1.3))


def validate_ticket_schema(raw_json: str) -> TicketClassification:
    """LLM çıktısını katı kurallarla doğrular (Schema Validation)."""
    # 1. JSON metnini Python sözlüğüne (dict) çeviriyoruz; bozuksa hata fırlatır.
    data: dict[str, Any] = json.loads(raw_json)

    # 2. Yalnızca izin verdiğimiz değerleri küme (set) olarak tanımlıyoruz (hızlı arama).
    allowed_categories = {"billing", "technical", "account"}
    allowed_priorities = {"low", "medium", "high"}

    # 3. Alanları güvenli şekilde okuyup küçük harfe çeviriyoruz (data.get hata vermez).
    category = str(data.get("category", "")).lower()
    priority = str(data.get("priority", "")).lower()
    summary = str(data.get("summary", "")).strip()

    # 4. İzin dışı bir değer geldiyse veritabanına yazmadan önce işlemi durduruyoruz.
    if category not in allowed_categories:
        raise ValueError(f"Geçersiz category: {category}")
    if priority not in allowed_priorities:
        raise ValueError(f"Geçersiz priority: {priority}")
    if not summary:
        raise ValueError("summary alanı boş olamaz.")

    # 5. Tüm kontroller geçti; artık güvenli ve tip korumalı nesnemizi döndürebiliriz.
    return TicketClassification(category=category, priority=priority, summary=summary)


def mock_structured_llm_call(user_message: str, config: LLMRequestConfig) -> str:
    """
    Harici API anahtarı olmadan Structured Outputs akışını test etmek için
    yerel deterministik simülatör. Gerçek projede burada OpenAI SDK çağrılır.
    """
    # API'ye gitmeden önce toplam Token bütçesini (System + User) kontrol ediyoruz.
    total_tokens = estimate_tokens(config.system_prompt) + estimate_tokens(user_message)
    if total_tokens > config.max_context_tokens:
        raise OverflowError(
            f"Context Window aşıldı! ({total_tokens} > {config.max_context_tokens})"
        )

    # Mesajı küçük harfe çevirip anahtar kelimelere göre örnek JSON hazırlıyoruz.
    lowered = user_message.lower()
    if "fatura" in lowered or "ödeme" in lowered:
        payload = {
            "category": "billing",
            "priority": "high",
            "summary": "Kullanıcı ödeme veya fatura sorunu bildiriyor.",
        }
    elif "şifre" in lowered or "giriş" in lowered:
        payload = {
            "category": "account",
            "priority": "medium",
            "summary": "Kullanıcı hesap erişim problemi yaşıyor.",
        }
    else:
        payload = {
            "category": "technical",
            "priority": "low",
            "summary": "Genel teknik destek talebi.",
        }

    # Python sözlüğünü Türkçe karakterleri koruyarak (ensure_ascii=False) JSON metnine çevirir.
    return json.dumps(payload, ensure_ascii=False)


def main() -> None:
    # 1. Ayar nesnesini oluşturuyoruz (Temperature=0.0).
    config = LLMRequestConfig(temperature=0.0)
    # 2. Denemek için örnek bir kullanıcı destek mesajı yazıyoruz. (Değiştirip tekrar deneyebilirsiniz!)
    user_ticket = "Kredi kartımdan bu ay iki kez fatura çekilmiş, acil kontrol eder misiniz?"

    # 3. Simüle edilmiş LLM'den ham JSON alıp şema doğrulamasından geçiriyoruz.
    raw_output = mock_structured_llm_call(user_ticket, config)
    validated = validate_ticket_schema(raw_output)

    print("Ham JSON Çıktısı:", raw_output)
    print("Doğrulanmış Nesne:", validated)
    print("Tahmini Token Sayısı:", estimate_tokens(user_ticket))


# Bu dosya doğrudan terminalden çalıştırıldığında main() fonksiyonunu başlatır.
if __name__ == "__main__":
    main()

Thread-Safe Tool Registry & Agent Loop — labs/mod02_tool_use_agent.py
Python 3.10+ • Thread-Safe
"""
Modül 2 Hands-On Lab: Tool Use, Function Calling ve Güvenli Agent Loop
- Thread-Safe ToolRegistry (RLock korumalı)
- Max-Steps koruması (Sonsuz döngü önleme)
- Hata yakalama ve güvenli Tool çağrısı
"""

from __future__ import annotations

import threading  # Birden fazla kullanıcı aynı anda eriştiğinde kilit (Lock) koymak için.
from dataclasses import dataclass
from typing import Any, Callable


@dataclass(frozen=True, slots=True)
class ToolDefinition:
    """Bir aracın (Tool) kimlik kartı: adı, açıklaması ve çalıştırılacak Python fonksiyonu."""

    name: str
    description: str
    handler: Callable[..., dict[str, Any]]  # Çağrılabilir Python fonksiyonu referansı.


class ThreadSafeToolRegistry:
    """Birden fazla Thread aynı anda erişse bile güvenli kalan Tool kayıt defteri."""

    def __init__(self) -> None:
        # RLock (Reentrant Lock): Aynı anda sadece 1 Thread'in sözlüğü değiştirmesine izin verir.
        self._lock = threading.RLock()
        self._tools: dict[str, ToolDefinition] = {}  # Kayıtlı araçları tutan sözlük.

    def register(self, tool: ToolDefinition) -> None:
        # "with self._lock:" bloğu bitince kilit otomatik açılır (hata olsa bile).
        with self._lock:
            self._tools[tool.name] = tool

    def execute(self, name: str, **kwargs: Any) -> dict[str, Any]:
        # **kwargs: Fonksiyona gönderilen isimlendirilmiş parametreleri (ör. order_id="ORD-101") toplar.
        with self._lock:
            tool = self._tools.get(name)
        if tool is None:
            return {"ok": False, "error": f"Bilinmeyen tool: {name}"}
        try:
            # KRİTİK: Aracı çalıştırırken kilidi tutmuyoruz! Böylece diğer kullanıcılar beklemez.
            result = tool.handler(**kwargs)
            return {"ok": True, "data": result}
        except Exception as exc:
            # Araç hata verse bile tüm Agent çökmez; hata mesajı düzenli bir sözlük olarak döner.
            return {"ok": False, "error": str(exc)}


def get_order_status(order_id: str) -> dict[str, Any]:
    """Örnek dış servis aracı (Tool): Sipariş durumunu sorgular."""
    # Gerçek projede burada SQL veritabanına veya REST API'ye istek atılır.
    fake_db = {
        "ORD-101": {"status": "Kargoda", "eta_days": 2},
        "ORD-202": {"status": "Teslim Edildi", "eta_days": 0},
    }
    if order_id not in fake_db:
        raise KeyError(f"Sipariş bulunamadı: {order_id}")
    return fake_db[order_id]


def calculate_shipping_discount(order_total: float) -> dict[str, Any]:
    """Örnek hesaplama aracı (Tool): Kargo indirimini kesin matematikle hesaplar."""
    # LLM matematikte yanılabilir; kesin kuralları her zaman Python Tool'u hesaplar.
    free_shipping = order_total >= 500.0
    return {"free_shipping": free_shipping, "shipping_fee": 0.0 if free_shipping else 49.90}


def run_agent_loop(user_query: str, registry: ThreadSafeToolRegistry, max_steps: int = 3) -> str:
    """Basitleştirilmiş Think -> Act -> Observe Agent Loop."""
    observations: list[str] = []  # Agent'ın önceki adımlarda gördüğü araç sonuçları.

    # max_steps sınırı sayesinde Agent asla sonsuz döngüye girip bütçenizi yakmaz.
    for step in range(1, max_steps + 1):
        # 1. THINK: Kullanıcı sorusunda "ORD-" geçiyorsa sipariş aracını seç.
        if "ORD-" in user_query and not observations:
            # Cümle içindeki "ORD-101" kodunu noktalama işaretlerinden temizleyip ayıklıyoruz.
            order_id = next(word.strip(".,?!") for word in user_query.split() if word.startswith("ORD-"))
            # 2. ACT: Seçilen aracı güvenli kayıt defteri (Registry) üzerinden çalıştır.
            tool_result = registry.execute("get_order_status", order_id=order_id)
            # 3. OBSERVE: Gelen sonucu gözlem listesine kaydet ve kullanıcıya anlaşılır cevap üret.
            observations.append(f"Adım {step} [get_order_status]: {tool_result}")
            if tool_result["ok"]:
                info = tool_result["data"]
                return (
                    f"Siparişiniz ({order_id}) şu an '{info['status']}' durumunda. "
                    f"Tahmini teslimat: {info['eta_days']} gün."
                )
            return f"Sipariş sorgulanamadı: {tool_result['error']}"

        # Kullanıcı kargo soruyorsa kargo hesaplama aracını çağır.
        if "kargo" in user_query.lower():
            tool_result = registry.execute("calculate_shipping_discount", order_total=650.0)
            return f"Kargo hesaplaması tamamlandı: {tool_result['data']}"

    return "Maksimum adım sayısına (max_steps) ulaşıldı; işlem güvenli şekilde durduruldu."


def main() -> None:
    # 1. Araç kayıt defterini oluştur ve iki farklı Tool kaydet.
    registry = ThreadSafeToolRegistry()
    registry.register(ToolDefinition("get_order_status", "Sipariş durumunu getirir", get_order_status))
    registry.register(
        ToolDefinition("calculate_shipping_discount", "Kargo ücretini hesaplar", calculate_shipping_discount)
    )

    # 2. Farklı sorularla Agent Loop'u test et. (ORD-999 yazarak hata yönetimini de deneyebilirsiniz!)
    print(run_agent_loop("Merhaba, ORD-101 numaralı siparişim nerede?", registry))
    print(run_agent_loop("650 TL alışverişte kargo ücreti ne kadar?", registry))


if __name__ == "__main__":
    main()

Modül 3: Agent Memory & State Management

03

1 Ne Öğreneceğiz & Neden Önemli?

LLM API'leri doğası gereği Stateless çalışır; her yeni istekte bir önceki mesajınızı unutur. Tutarlı bir asistan oluşturmak için hem son konuşmaları (Short-Term Memory) hem de kalıcı kullanıcı tercihlerini (Long-Term Memory) kullanıcı bazlı izole biçimde yönetmeliyiz.

Günlük Hayattan Benzetme
Bir doktor her hastanın geçmişini ezberlemez. Masadaki güncel muayene notlarını (Short-Term Memory) ve hastanın kronik alerjilerinin yazılı olduğu dosyayı (Long-Term Memory) birlikte kullanır.

"""
Modül 3 Hands-On Lab: Agent Memory & State Management
- Bounded Short-Term Memory (deque(maxlen=N) ile bellek sızıntısı önlenir)
- Session bazlı izole State Store (Thread-Safe RLock)
- Long-Term Memory (kalıcı kullanıcı tercihleri)
"""

from __future__ import annotations

import threading
from collections import deque  # Sabit boyutlu (maxlen) yüksek hızlı kuyruk veri yapısı.
from dataclasses import dataclass, field


@dataclass(frozen=True, slots=True)
class Message:
    """Tek bir sohbet mesajı (değiştirilemez / Immutable)."""

    role: str     # "user" veya "assistant"
    content: str  # Mesajın metni


@dataclass(slots=True)
class SessionState:
    """Tek bir kullanıcı oturumuna (Session) ait izole bellek kutusu."""

    session_id: str
    # field(default_factory=...): Her yeni oturum için taze, birbirinden bağımsız bir kuyruk açar.
    short_term: deque[Message] = field(default_factory=lambda: deque(maxlen=6))
    long_term_facts: dict[str, str] = field(default_factory=dict)


class ThreadSafeMemoryManager:
    """Her kullanıcı oturumu (Session) için izole ve Thread-Safe bellek yöneticisi."""

    def __init__(self, max_short_term_messages: int = 6) -> None:
        self._lock = threading.RLock()  # Eşzamanlı erişimlerde veri bozulmasını önler.
        self._max_messages = max_short_term_messages
        self._sessions: dict[str, SessionState] = {}  # session_id -> SessionState eşleşmesi.

    def _get_or_create(self, session_id: str) -> SessionState:
        """Oturum daha önce açılmadıysa yeni bir izole SessionState oluşturur."""
        state = self._sessions.get(session_id)
        if state is None:
            state = SessionState(
                session_id=session_id,
                # maxlen dolduğunda yeni mesaj gelince en eski mesaj otomatik silinir.
                short_term=deque(maxlen=self._max_messages),
            )
            self._sessions[session_id] = state
        return state

    def add_message(self, session_id: str, role: str, content: str) -> None:
        """Kısa süreli belleğe (Short-Term Memory) yeni mesaj ekler."""
        with self._lock:
            state = self._get_or_create(session_id)
            state.short_term.append(Message(role=role, content=content))

    def save_long_term_fact(self, session_id: str, key: str, value: str) -> None:
        """Kullanıcıya dair kalıcı bilgiyi (Long-Term Memory) kaydeder."""
        with self._lock:
            state = self._get_or_create(session_id)
            state.long_term_facts[key] = value

    def build_context_snapshot(self, session_id: str) -> dict[str, object]:
        """Dışarıya kopya (snapshot) döndürür; böylece dış kod iç state'i bozamaz."""
        with self._lock:
            state = self._get_or_create(session_id)
            # dict(...) ve list(...) çağrıları orijinal belleğin güvenli birer kopyasını üretir.
            return {
                "session_id": state.session_id,
                "long_term_facts": dict(state.long_term_facts),
                "recent_messages": list(state.short_term),
            }


def main() -> None:
    # En fazla 4 kısa süreli mesaj tutan bellek yöneticisi başlatıyoruz.
    memory = ThreadSafeMemoryManager(max_short_term_messages=4)
    session = "user-junior-01"

    # Kalıcı tercihleri (Long-Term) kaydediyoruz; mesajlar dolsa bile bunlar silinmez.
    memory.save_long_term_fact(session, "preferred_language", "Python")
    memory.save_long_term_fact(session, "experience_level", "Junior")

    # 6 mesaj ekliyoruz; maxlen=4 olduğu için ilk 2 mesaj otomatik düşecek!
    for i in range(1, 7):
        memory.add_message(session, "user", f"Soru {i}: Agent Memory nasıl çalışır?")

    # Güvenli kopyayı (Snapshot) alıp ekrana yazdırıyoruz.
    snapshot = memory.build_context_snapshot(session)
    print("Long-Term Facts:", snapshot["long_term_facts"])
    print(f"Short-Term Mesaj Sayısı (maxlen=4): {len(snapshot['recent_messages'])}")
    for msg in snapshot["recent_messages"]:
        print(f"  - [{msg.role}] {msg.content}")


if __name__ == "__main__":
    main()

Python 3.10+ • Thread-Safe
"""
Modül 4 Hands-On Lab: RAG, Vector Database Mantığı ve Agentic RAG
- Chunking (metni parçalara bölme)
- Hafif Cosine Similarity tabanlı yerel Vector Store (Thread-Safe)
- Agentic RAG: İlk arama zayıfsa sorguyu yeniden yazıp (Query Rewrite) tekrar arama
"""

from __future__ import annotations

import math  # Karekök (sqrt) ile vektör uzunluğunu normalize etmek için.
import re
import threading
from collections import Counter  # Her kelimenin metinde kaç kez geçtiğini hızlıca sayar.
from dataclasses import dataclass

# Türkçe karakterleri de kapsayan kelime ayırıcı Regex (1 kez derlenir).
_TOKEN_RE = re.compile(r"[a-zA-ZçğıöşüÇĞİÖŞÜ0-9]+")


def text_to_vector(text: str) -> dict[str, float]:
    """Eğitim amaçlı hafif Term-Frequency vektörü. Gerçek sistemde Embedding API kullanılır."""
    # 1. Metindeki tüm kelimeleri küçük harfe çevirip listeye alıyoruz.
    tokens = [t.lower() for t in _TOKEN_RE.findall(text)]
    # 2. Hangi kelime kaç kez geçmiş sayıyoruz (ör. {"iade": 2, "gün": 1}).
    counts = Counter(tokens)
    # 3. Vektörü 1 birim uzunluğa normalize ediyoruz (Cosine Similarity hesabı için).
    norm = math.sqrt(sum(v * v for v in counts.values())) or 1.0
    return {k: v / norm for k, v in counts.items()}


def cosine_similarity(vec_a: dict[str, float], vec_b: dict[str, float]) -> float:
    """İki normalize vektör arasındaki benzerlik skoru (0.0 = alakasız, 1.0 = birebir aynı)."""
    # Performans optimizasyonu: Her zaman daha az elemanı olan sözlükte döngü kurarız.
    if len(vec_a) > len(vec_b):
        vec_a, vec_b = vec_b, vec_a
    # Ortak kelimelerin ağırlıklarını çarpıp topluyoruz (Dot Product).
    return sum(val * vec_b.get(key, 0.0) for key, val in vec_a.items())


@dataclass(frozen=True, slots=True)
class DocumentChunk:
    """Veritabanında saklanan tek bir metin parçası (Chunk) ve onun sayısal vektörü."""

    chunk_id: str
    content: str
    vector: dict[str, float]


class ThreadSafeVectorStore:
    """Bellek içi (In-Memory) Thread-Safe Vector Store."""

    def __init__(self) -> None:
        self._lock = threading.RLock()
        self._chunks: list[DocumentChunk] = []

    def add_document(self, doc_id: str, text: str, chunk_size: int = 120) -> None:
        """Uzun metni chunk_size karakterlik parçalara böler (Chunking) ve vektörleştirir."""
        parts = [text[i : i + chunk_size].strip() for i in range(0, len(text), chunk_size)]
        new_chunks = [
            DocumentChunk(f"{doc_id}-{idx}", part, text_to_vector(part))
            for idx, part in enumerate(parts)
            if part
        ]
        # Kilit yalnızca listeye yeni parçaları eklerken tutulur.
        with self._lock:
            self._chunks.extend(new_chunks)

    def search(self, query: str, top_k: int = 2) -> list[tuple[float, DocumentChunk]]:
        """Sorguyu vektöre çevirir ve en yüksek benzerlik skoruna sahip top_k parçayı döndürür."""
        q_vec = text_to_vector(query)
        with self._lock:
            snapshot = list(self._chunks)  # Güvenli kopya üzerinde arama yapıyoruz.
        scored = [(cosine_similarity(q_vec, chunk.vector), chunk) for chunk in snapshot]
        # En yüksek skordan en düşüğe doğru sıralıyoruz.
        scored.sort(key=lambda item: item[0], reverse=True)
        return scored[:top_k]


def agentic_rag_search(store: ThreadSafeVectorStore, user_query: str, min_score: float = 0.25) -> str:
    """
    Agentic RAG Döngüsü:
    1. İlk sorguyu çalıştır.
    2. Benzerlik skoru eşiğin altındaysa sorguyu genişlet (Query Rewrite) ve tekrar ara.
    """
    # Adım 1: Kullanıcının ham sorusuyla ilk aramayı yap.
    results = store.search(user_query, top_k=1)
    if results and results[0][0] >= min_score:
        score, chunk = results[0]
        return f"[İlk Aramada Bulundu | Skor: {score:.2f}] -> {chunk.content}"

    # Adım 2: Skor zayıfsa (ör. kullanıcı teknik terim bilmiyorsa) sorguyu zenginleştir.
    rewritten_query = f"{user_query} iade politikası süre gün kargo"
    retry_results = store.search(rewritten_query, top_k=1)
    if retry_results and retry_results[0][0] > 0.0:
        score, chunk = retry_results[0]
        return (
            f"[Agentic Query Rewrite Uygulandı | Yeni Skor: {score:.2f}] -> {chunk.content}"
        )
    return "İlgili bilgi veri tabanında bulunamadı."


def main() -> None:
    # 1. Yerel Vector Store oluştur ve iki şirket dokümanı yükle.
    store = ThreadSafeVectorStore()
    store.add_document(
        "policy",
        "Müşteriler teslimattan itibaren 14 gün içinde ücretsiz kargo ile iade politikası kapsamında ürün iade edebilir.",
    )
    store.add_document(
        "support",
        "Teknik destek ekibi hafta içi 09:00 - 18:00 saatleri arasında canlı sohbet hizmeti verir.",
    )

    # 2. Net soru ilk seferde bulunur; belirsiz soru ise Query Rewrite ile kurtarılır.
    print("Sorgu 1 (Net):", agentic_rag_search(store, "iade politikası kaç gün?"))
    print("Sorgu 2 (Belirsiz):", agentic_rag_search(store, "beğenmezsem geri verebilir miyim?"))


if __name__ == "__main__":
    main()

JSON-RPC 2.0 MCP Server & Client Discovery — labs/mod05_mcp_client_server.py
Python 3.10+ • Thread-Safe
"""
Modül 5 Hands-On Lab: Model Context Protocol (MCP) Mimarisi
- JSON-RPC 2.0 tabanlı standart MCP Tool keşfi (tools/list) ve çağrısı (tools/call)
- MCP Server ve MCP Client soyutlaması (Thread-Safe)
"""

from __future__ import annotations

import json  # JSON-RPC 2.0 isteklerini okuyup yanıt üretmek için.
import threading
from dataclasses import dataclass
from typing import Any, Callable


@dataclass(frozen=True, slots=True)
class MCPToolSpec:
    """MCP Server üzerinde dış dünyaya açılan tek bir aracın standart tanımı."""

    name: str                                         # Aracın benzersiz adı
    description: str                                  # LLM'in okuyacağı görev açıklaması
    input_schema: dict[str, Any]                      # Aracın beklediği parametrelerin JSON şeması
    handler: Callable[[dict[str, Any]], dict[str, Any]]  # Gerçek işi yapan Python fonksiyonu


class SimpleMCPServer:
    """JSON-RPC 2.0 mesajlarını işleyen minimal, Thread-Safe MCP Server."""

    def __init__(self, server_name: str) -> None:
        self.server_name = server_name
        self._lock = threading.RLock()  # Eşzamanlı araç kaydı ve okumasını korur.
        self._tools: dict[str, MCPToolSpec] = {}

    def register_tool(self, spec: MCPToolSpec) -> None:
        """Sunucuya yeni bir MCP aracı (Tool) kaydeder."""
        with self._lock:
            self._tools[spec.name] = spec

    def handle_json_rpc(self, raw_request: str) -> str:
        """Gelen standart JSON-RPC 2.0 mesajını okur, ilgili MCP metodunu çalıştırır."""
        # 1. İstemciden (MCP Client) gelen JSON metnini Python sözlüğüne çeviriyoruz.
        req = json.loads(raw_request)
        req_id = req.get("id")          # Hangi isteğe yanıt verdiğimizi eşleştiren kimlik.
        method = req.get("method")      # "tools/list" veya "tools/call"
        params = req.get("params", {})  # Çağrı parametreleri (yoksa boş sözlük).

        # 2. KEŞİF (Tool Discovery): İstemci "Hangi araçların var?" diye soruyor.
        if method == "tools/list":
            with self._lock:
                tools_meta = [
                    {
                        "name": t.name,
                        "description": t.description,
                        "inputSchema": t.input_schema,
                    }
                    for t in self._tools.values()
                ]
            return json.dumps({"jsonrpc": "2.0", "id": req_id, "result": {"tools": tools_meta}}, ensure_ascii=False)

        # 3. ÇALIŞTIRMA (Tool Execution): İstemci belirli bir aracı argümanlarıyla çağırıyor.
        if method == "tools/call":
            tool_name = params.get("name")
            arguments = params.get("arguments", {})
            with self._lock:
                spec = self._tools.get(tool_name)
            if spec is None:
                # Standart JSON-RPC -32601 hata kodu: "Method/Tool bulunamadı".
                return json.dumps(
                    {"jsonrpc": "2.0", "id": req_id, "error": {"code": -32601, "message": "Tool not found"}},
                    ensure_ascii=False,
                )
            # Aracı kilit dışında çalıştırıp sonucu standart JSON-RPC formatında döndürüyoruz.
            output = spec.handler(arguments)
            return json.dumps({"jsonrpc": "2.0", "id": req_id, "result": output}, ensure_ascii=False)

        # Desteklenmeyen bir metot adı geldiyse standart hata döndür.
        return json.dumps(
            {"jsonrpc": "2.0", "id": req_id, "error": {"code": -32601, "message": "Method not found"}},
            ensure_ascii=False,
        )


def check_inventory(args: dict[str, Any]) -> dict[str, Any]:
    """Örnek arka uç (Backend) fonksiyonu: Verilen ürün kodunun (SKU) stoğunu döndürür."""
    sku = str(args.get("sku", ""))
    stock = {"SKU-LAPTOP-01": 12, "SKU-MOUSE-02": 0}
    return {"sku": sku, "in_stock": stock.get(sku, 0)}


def main() -> None:
    # 1. Bir MCP Server ayağa kaldırıp depo stok aracını kaydediyoruz.
    server = SimpleMCPServer("warehouse-mcp")
    server.register_tool(
        MCPToolSpec(
            name="check_inventory",
            description="Depo stok durumunu SKU koduna göre sorgular.",
            input_schema={"type": "object", "properties": {"sku": {"type": "string"}}, "required": ["sku"]},
            handler=check_inventory,
        )
    )

    # 2. MCP Client önce sunucuda hangi Tool'lar var diye keşif yapar (tools/list).
    list_req = json.dumps({"jsonrpc": "2.0", "id": 1, "method": "tools/list"})
    print("MCP tools/list Yanıtı:", server.handle_json_rpc(list_req))

    # 3. MCP Client standart formatla Tool çağırır (tools/call). (SKU-MOUSE-02 ile de deneyin!)
    call_req = json.dumps(
        {
            "jsonrpc": "2.0",
            "id": 2,
            "method": "tools/call",
            "params": {"name": "check_inventory", "arguments": {"sku": "SKU-LAPTOP-01"}},
        }
    )
    print("MCP tools/call Yanıtı:", server.handle_json_rpc(call_req))


if __name__ == "__main__":
    main()

Immutable State Graph Engine (Planner -> Writer -> Reviewer) — labs/mod06_stateful_workflow.py
Python 3.10+ • Thread-Safe
"""
Modül 6 Hands-On Lab: Planning & Multi-Agent Stateful Workflow (LangGraph Mantığı)
- Node (Düğüm) ve Edge (Geçiş) tabanlı deterministik graf motoru
- Immutable State kopyalaması ile %100 Thread-Safe yürütme
- Koşullu yönlendirme (Conditional Edge): Reviewer onaylamazsa Writer'a geri döner
"""

from __future__ import annotations

# replace: frozen (değiştirilemez) bir dataclass'tan tek bir alanı güncellenmiş yeni kopya üretir.
from dataclasses import dataclass, replace
from typing import Callable


@dataclass(frozen=True, slots=True)
class WorkflowState:
    """Tüm düğümler (Nodes) arasında taşınan değiştirilemez (Immutable) iş akışı durumu."""

    topic: str
    plan: tuple[str, ...] = ()  # list yerine tuple kullanıyoruz çünkü tuple değiştirilemezdir!
    draft: str = ""
    review_passed: bool = False
    revision_count: int = 0


def planner_node(state: WorkflowState) -> WorkflowState:
    """1. Ajan (Planner): Büyük konuyu 3 net alt adıma böler."""
    steps = (
        f"{state.topic} nedir?",
        "Neden Production ortamında kritik önem taşır?",
        "Basit bir uygulama örneği",
    )
    # Mevcut state'i bozmuyoruz; yalnızca 'plan' alanı dolu yeni bir WorkflowState döndürüyoruz.
    return replace(state, plan=steps)


def writer_node(state: WorkflowState) -> WorkflowState:
    """2. Ajan (Writer): Plana göre taslak metin üretir."""
    if state.revision_count == 0:
        # İlk taslağı bilerek kısa bırakıyoruz ki Reviewer'ın reddedip geri gönderdiğini görelim.
        draft = f"{state.topic} önemlidir."
    else:
        # 2. turda (revizyonda) tüm plan maddelerini ve 'Örnek:' bölümünü ekleyerek düzeltiyoruz.
        bullet_text = " | ".join(state.plan)
        draft = f"{state.topic} kapsamlı özet -> {bullet_text}. Örnek: State izole edilmelidir."
    return replace(state, draft=draft, revision_count=state.revision_count + 1)


def reviewer_node(state: WorkflowState) -> WorkflowState:
    """3. Ajan (Reviewer): Taslağın kalite kriterlerine uyup uymadığını denetler."""
    # Kalite kuralı: Taslak en az 50 karakter olmalı VE içinde "Örnek:" kelimesi geçmeli.
    passed = len(state.draft) >= 50 and "Örnek:" in state.draft
    return replace(state, review_passed=passed)


def run_stateful_graph(initial_state: WorkflowState, max_revisions: int = 3) -> WorkflowState:
    """LangGraph benzeri koşullu geçişli (Conditional Edge) yürütme motoru."""
    # Graf üzerindeki tüm düğümleri (Nodes) isim -> fonksiyon sözlüğü olarak tanımlıyoruz.
    nodes: dict[str, Callable[[WorkflowState], WorkflowState]] = {
        "planner": planner_node,
        "writer": writer_node,
        "reviewer": reviewer_node,
    }

    current_node = "planner"  # Akış her zaman 'planner' düğümünden başlar.
    state = initial_state

    # "END" düğümüne ulaşana kadar grafı adım adım yürütüyoruz.
    while current_node != "END":
        print(f"[GRAPH] Çalıştırılan Node: {current_node}")
        # Aktif düğümün fonksiyonunu çağırıp güncellenmiş yeni State'i alıyoruz.
        state = nodes[current_node](state)

        # Edge (Geçiş) Kuralları: Bir sonraki düğüm hangisi olacak?
        if current_node == "planner":
            current_node = "writer"
        elif current_node == "writer":
            current_node = "reviewer"
        elif current_node == "reviewer":
            # Conditional Edge: Onaylandıysa veya revizyon hakkı bittiyse bitir; yoksa Writer'a dön!
            if state.review_passed or state.revision_count >= max_revisions:
                current_node = "END"
            else:
                print("[GRAPH] Reviewer reddetti -> Writer düğümüne geri dönülüyor.")
                current_node = "writer"

    return state


def main() -> None:
    # Başlangıç konusunu verip grafı başlatıyoruz. (topic metnini değiştirip tekrar çalıştırabilirsiniz!)
    final_state = run_stateful_graph(WorkflowState(topic="Agentic AI State Management"))
    print("\n--- SONUÇ ---")
    print("Onay Durumu:", final_state.review_passed)
    print("Revizyon Sayısı:", final_state.revision_count)
    print("Nihai Taslak:", final_state.draft)


if __name__ == "__main__":
    main()

Retry, Fallback, Observability Trace & Evaluation — labs/mod07_production_guardrails.py
Python 3.10+ • Thread-Safe
"""
Modül 7 Hands-On Lab: Production-Ready Engineering
- Structured Observability Trace (LangSmith mantığı)
- Retry + Exponential Backoff + Fallback mekanizması
- Otomatik Evaluation (Deterministic Assert Checks)
- Thread-Safe Trace Collector
"""

from __future__ import annotations

import threading
import time  # Milisaniye hassasiyetinde süre ölçmek (perf_counter) ve beklemek (sleep) için.
from dataclasses import dataclass
from typing import Callable


@dataclass(frozen=True, slots=True)
class TraceEvent:
    """Uçağın kara kutusundaki tek bir kayıt satırı (Span): Ne çalıştı, kaç ms sürdü?"""

    span_name: str
    duration_ms: float
    status: str   # "OK" veya "ERROR"
    detail: str


class ThreadSafeTracer:
    """Production Observability için Thread-Safe izleme (Tracing) toplayıcısı."""

    def __init__(self) -> None:
        self._lock = threading.RLock()
        self._events: list[TraceEvent] = []

    def record(self, event: TraceEvent) -> None:
        """Yeni bir izleme kaydını güvenli biçimde listeye ekler."""
        with self._lock:
            self._events.append(event)

    def snapshot(self) -> list[TraceEvent]:
        """Kayıtların güvenli bir kopyasını döndürür."""
        with self._lock:
            return list(self._events)


def call_with_retry_and_fallback(
    primary_fn: Callable[[], str],
    fallback_fn: Callable[[], str],
    tracer: ThreadSafeTracer,
    max_retries: int = 2,
) -> str:
    """Geçici API hatalarında Retry yapar; başarısız olursa Fallback modele geçer."""
    # 1 ilk deneme + max_retries tekrar denemesi = toplam max_retries + 1 tur.
    for attempt in range(1, max_retries + 2):
        start = time.perf_counter()  # Yüksek hassasiyetli kronometreyi başlat.
        try:
            result = primary_fn()
            elapsed = (time.perf_counter() - start) * 1000  # Saniyeyi milisaniyeye çevir.
            tracer.record(TraceEvent("primary_llm", elapsed, "OK", f"attempt={attempt}"))
            return result
        except RuntimeError as exc:
            # Hata alındığında süreyi ve hata mesajını kara kutuya (Tracer) yazıyoruz.
            elapsed = (time.perf_counter() - start) * 1000
            tracer.record(TraceEvent("primary_llm", elapsed, "ERROR", f"attempt={attempt}: {exc}"))
            if attempt <= max_retries:
                # Exponential Backoff: Sunucuyu boğmamak için her denemede biraz daha fazla bekle.
                time.sleep(0.05 * attempt)

    # Birincil model tüm denemelerde başarısız oldu -> Yedek (Fallback) devreye giriyor!
    start = time.perf_counter()
    fallback_result = fallback_fn()
    elapsed = (time.perf_counter() - start) * 1000
    tracer.record(TraceEvent("fallback_llm", elapsed, "OK", "fallback_triggered"))
    return fallback_result


def evaluate_response(response: str, required_keywords: tuple[str, ...]) -> dict[str, object]:
    """Basit otomatik Evaluation: Dönen cevap zorunlu bilgileri eksiksiz içeriyor mu?"""
    lowered = response.lower()
    # Eksik kalan anahtar kelimeleri tek satırda (List Comprehension) buluyoruz.
    missing = [kw for kw in required_keywords if kw.lower() not in lowered]
    return {"passed": len(missing) == 0, "missing_keywords": missing}


def main() -> None:
    tracer = ThreadSafeTracer()
    attempts = {"count": 0}

    def unstable_primary() -> str:
        # Canlı ortamdaki geçici API hız sınırı (429 Rate Limit) hatasını simüle ediyoruz.
        attempts["count"] += 1
        raise RuntimeError("429 Rate Limit Exceeded")

    def reliable_fallback() -> str:
        # Birincil model çöktüğünde kullanıcıyı yarı yolda bırakmayan yedek yanıt.
        return "İade süresi 14 gündür ve kargo ücretsizdir."

    # 1. Retry + Fallback korumasıyla çağrıyı çalıştır.
    answer = call_with_retry_and_fallback(unstable_primary, reliable_fallback, tracer, max_retries=2)
    # 2. Üretilen cevabı otomatik Evaluation testinden geçir.
    eval_report = evaluate_response(answer, required_keywords=("14 gün", "ücretsiz"))

    print("Nihai Cevap:", answer)
    print("Evaluation Raporu:", eval_report)
    print("\n--- OBSERVABILITY TRACE ---")
    for ev in tracer.snapshot():
        print(f"  [{ev.status}] {ev.span_name} ({ev.duration_ms:.2f} ms) -> {ev.detail}")


if __name__ == "__main__":
    main()

End-to-End Concurrent Production Support Agent — labs/mod08_capstone_agent.py
Python 3.10+ • Thread-Safe
"""
Modül 8 Hands-On Lab: Capstone Mini-Project (End-to-End Customer Support Agent)
Tüm modüllerin tek bir Thread-Safe sistemde birleşimi:
- Memory & Session State (Modül 3)
- Agentic RAG Bilgi Bankası (Modül 4)
- Tool Use (Sipariş Sorgulama) (Modül 2)
- Observability Trace & Evaluation (Modül 7)
"""

from __future__ import annotations

import threading
import time
from collections import deque
# ThreadPoolExecutor: Aynı anda birden fazla müşteri isteğini paralel çalıştırır (Concurrency).
from concurrent.futures import ThreadPoolExecutor
from dataclasses import dataclass, field


@dataclass(frozen=True, slots=True)
class TraceSpan:
    """Her müşteri isteğinin hangi rotadan geçtiğini ve kaç ms sürdüğünü kaydeder."""

    session_id: str
    step: str
    latency_ms: float
    outcome: str


@dataclass(slots=True)
class SupportSession:
    """Her müşteriye özel son 5 mesajlık sınırlı konuşma geçmişi (Bounded Memory)."""

    session_id: str
    history: deque[str] = field(default_factory=lambda: deque(maxlen=5))


class ProductionSupportAgent:
    """Eşzamanlı (Concurrent) müşteri isteklerini güvenle işleyen Capstone Agent."""

    def __init__(self) -> None:
        self._lock = threading.RLock()  # Paylaşılan oturum ve trace listelerini korur.
        self._sessions: dict[str, SupportSession] = {}
        self._traces: list[TraceSpan] = []
        # Salt-okunur (Read-Only) bilgi bankası (RAG kaynağı) ve sipariş tablosu (Tool kaynağı).
        self._knowledge_base = {
            "iade": "Teslimattan itibaren 14 gün içinde ücretsiz iade hakkınız vardır.",
            "garanti": "Tüm elektronik ürünlerde 24 ay resmi distribütör garantisi bulunur.",
        }
        self._orders = {
            "ORD-500": "Hazırlanıyor (Tahmini kargo: Yarın)",
            "ORD-501": "Kargoda (Takip No: TR998877)",
        }

    def _get_session(self, session_id: str) -> SupportSession:
        """Müşterinin oturumunu bulur; ilk kez geliyorsa izole yeni bir oturum açar."""
        with self._lock:
            sess = self._sessions.get(session_id)
            if sess is None:
                sess = SupportSession(session_id=session_id)
                self._sessions[session_id] = sess
            return sess

    def _record_trace(self, span: TraceSpan) -> None:
        with self._lock:
            self._traces.append(span)

    def handle_request(self, session_id: str, user_message: str) -> str:
        """Tek bir müşteri isteğini uçtan uca işler: Memory -> Routing -> Tool/RAG -> Trace."""
        start = time.perf_counter()
        session = self._get_session(session_id)

        # Kullanıcının sorusunu kendi oturumunun kısa süreli belleğine kaydet.
        with self._lock:
            session.history.append(f"USER: {user_message}")

        lowered = user_message.lower()
        # 1. ROUTING -> Tool Use: Mesajda sipariş kodu ("ord-") geçiyorsa sipariş aracını kullan.
        if "ord-" in lowered:
            order_id = next(
                tok.strip(".,?!").upper() for tok in user_message.split() if tok.lower().startswith("ord-")
            )
            status = self._orders.get(order_id, "Sipariş bulunamadı.")
            reply = f"[Tool:OrderLookup] {order_id} durumu -> {status}"
            step_name = "tool_order_lookup"
        # 2. ROUTING -> RAG: İade veya garanti soruluyorsa şirket bilgi bankasından çek.
        elif "iade" in lowered or "geri" in lowered:
            reply = f"[RAG:Policy] {self._knowledge_base['iade']}"
            step_name = "rag_policy_search"
        elif "garanti" in lowered:
            reply = f"[RAG:Policy] {self._knowledge_base['garanti']}"
            step_name = "rag_policy_search"
        # 3. ROUTING -> Fallback: Anlaşılmayan soruda halüsinasyon yerine netleştirme iste.
        else:
            reply = "[Fallback] Talebinizi netleştirebilir misiniz? Sipariş (ORD-XXX), iade veya garanti sorabilirsiniz."
            step_name = "fallback_clarify"

        # Agent yanıtını da oturum belleğine kaydet.
        with self._lock:
            session.history.append(f"AGENT: {reply}")

        # Toplam gecikmeyi (Latency) hesaplayıp Observability kaydını oluştur.
        latency = (time.perf_counter() - start) * 1000
        self._record_trace(TraceSpan(session_id, step_name, latency, "SUCCESS"))
        return reply

    def get_traces(self) -> list[TraceSpan]:
        with self._lock:
            return list(self._traces)


def main() -> None:
    agent = ProductionSupportAgent()
    # Aynı anda sisteme giren 4 farklı müşteri isteği (sess-1 iki kez soru soruyor).
    requests = [
        ("sess-1", "ORD-500 siparişim ne durumda?"),
        ("sess-2", "Ürünü beğenmezsem iade süresi kaç gün?"),
        ("sess-3", "Kulaklıkların garanti süresi ne kadar?"),
        ("sess-1", "Teşekkürler, peki ORD-501 nerede?"),
    ]

    # Thread-Safety testi: 4 iş parçacığı (Worker Thread) aynı anda agent.handle_request çağırır.
    with ThreadPoolExecutor(max_workers=4) as executor:
        # executor.submit(...) her isteği arka planda anında başlatır ve bir Future nesnesi döner.
        futures = [executor.submit(agent.handle_request, sid, msg) for sid, msg in requests]
        # fut.result() ilgili Thread işini bitirdiğinde sonucu güvenle alır.
        for (sid, msg), fut in zip(requests, futures):
            print(f"[{sid}] Soru: {msg}")
            print(f"[{sid}] Yanıt: {fut.result()}\n")

    print("--- CAPSTONE OBSERVABILITY TRACES ---")
    for span in agent.get_traces():
        print(f"  {span.session_id} | {span.step} | {span.latency_ms:.3f} ms | {span.outcome}")


if __name__ == "__main__":
    main()
